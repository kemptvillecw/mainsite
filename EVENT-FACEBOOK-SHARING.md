# Per-event Facebook sharing

The public Schedule & Events calendar exposes **Share to Facebook** only for upcoming Published Google Calendar events whose generated share artifact has already reached this site.

The browser checks for `share/events/<google-calendar-event-id>.html`. If the file exists, the button opens Facebook's standard sharer in a new tab. The KCW site never authenticates the visitor with Facebook and never posts on the visitor's behalf.

The Google Calendar event ID is also assigned to the rendered event row, so a generated share artifact can redirect human visitors to `schedule.html#<event-id>`.

Share artifacts are generated by Calendar Manager and synchronized into the `dev` branch. They then follow the normal KCW dev → UAT → main promotion process. Archived, Draft, and cancelled events do not appear in this upcoming public calendar, so they do not receive a Share button. Existing share files are intentionally retained so older Facebook posts do not break.
